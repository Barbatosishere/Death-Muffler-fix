# Death Muffler Fix (1.12.2 — Forge)

A client-side fix for the **Death Muffler** boss bar hiding feature in [Mob Grinding Utils](https://www.curseforge.com/minecraft/mc-mods/mob-grinding-utils) 0.3.13.

## The Problem

In MUG 0.3.13, the boss bar hiding logic works — but it matches boss names with **hardcoded English strings using exact equality**:

```java
bossName.equals("Wither")         // exact match
bossName.equals("Ender Dragon")   // exact match
```

Two failure modes result:

1. **Non-English locales**: the boss bar shows the localized name (e.g. "凋灵", "末影龙"), the `equals()` check fails, and the hiding silently does nothing.
2. **Any custom-named boss**: since the match is exact (not `contains`), even a renamed Wither in English ("Evil Wither") would not be hidden.

## The Fix

This mod registers an additional `RenderGameOverlayEvent.BossInfo` listener that matches boss names via Minecraft's **localization system** with substring matching:

```java
String witherName = I18n.format("entity.Wither.name");   // localized at runtime
bossName.contains(witherName) → cancel the boss bar render
```

It reads the same boss bar capability flags MUG uses (`renderWitherBar()` / `renderEnderDragonBar()`, toggled by the Death Muffler upgrades), so the hiding behavior stays in sync with your in-game settings — in **every language**, and tolerant of custom names.

The listener **stacks on top of** MUG's original one (a static `@SubscribeEvent` handler alongside the original), which keeps running unchanged — including its extra logic such as Wither Crumbs boss detection. No conflict.

## Requirements

| Component | Version |
|---|---|
| Minecraft | 1.12.2 |
| Loader | Forge 14.23.5.2847+ |
| Mob Grinding Utils | 0.3.13+ (required) |
| Java | 8 |

## Installation

1. Install Forge and Mob Grinding Utils
2. Drop `death_muffler_fix-1.0.0-Forge-1.12.2.jar` (the one **without** the `-dev` suffix) into your `mods` folder
3. Launch the game

## Notes

- Client-side only; works on any server (vanilla or modded).
- No configuration — the mod activates automatically based on your Death Muffler upgrades.
- This mod **requires** Mob Grinding Utils and will refuse to load without it.
