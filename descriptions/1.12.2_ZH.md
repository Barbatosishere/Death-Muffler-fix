# Death Muffler Fix（1.12.2 — Forge）

修复 [实用设备（Mob Grinding Utils）](https://www.curseforge.com/minecraft/mc-mods/mob-grinding-utils) 0.3.13 消声器（Death Muffler）Boss 血条隐藏功能的客户端修复模组。

## 问题背景

MUG 0.3.13 中的血条隐藏逻辑可以运行——但它使用**硬编码英文字符串的精确等值匹配**：

```java
bossName.equals("Wither")         // 精确匹配
bossName.equals("Ender Dragon")   // 精确匹配
```

由此产生两类失效场景：

1. **非英文环境**：Boss 血条显示本地化名称（如"凋灵"、"末影龙"），`equals()` 匹配失败，隐藏功能静默失效。
2. **自定义命名的 Boss**：由于是精确匹配（而非包含匹配），即使是英文环境下改名的凋灵（如 "Evil Wither"）也不会被隐藏。

## 修复方案

本模组注册了一个额外的 `RenderGameOverlayEvent.BossInfo` 监听器，改用 Minecraft 的**语言系统**进行包含式匹配：

```java
String witherName = I18n.format("entity.Wither.name");   // 运行时按当前语言解析
bossName.contains(witherName) → 取消血条渲染
```

监听器读取与 MUG 相同的 Boss 血条能力标记（`renderWitherBar()` / `renderEnderDragonBar()`，由消声器升级切换），因此隐藏行为与游戏内设置保持同步——在**任何语言**下均生效，且兼容自定义命名的 Boss。

该监听器（静态 `@SubscribeEvent` 处理器）与 MUG 原版监听器**叠加共存**，原版保持原样继续运行——包括其额外逻辑（如 Wither Crumbs 模组 Boss 检测）。互不冲突。

## 依赖要求

| 组件 | 版本 |
|---|---|
| Minecraft | 1.12.2 |
| 加载器 | Forge 14.23.5.2847+ |
| 实用设备（MUG） | 0.3.13+（必需） |
| Java | 8 |

## 安装方法

1. 安装 Forge 和实用设备（Mob Grinding Utils）
2. 将 `death_muffler_fix-1.0.0-Forge-1.12.2.jar`（**不带** `-dev` 后缀的那个）放入 `mods` 文件夹
3. 启动游戏

## 说明

- 纯客户端模组，在任何服务器（原版或模组服）上均可使用。
- 无需配置——模组根据你的消声器升级状态自动生效。
- 本模组**依赖**实用设备（Mob Grinding Utils），未安装时将拒绝加载。
