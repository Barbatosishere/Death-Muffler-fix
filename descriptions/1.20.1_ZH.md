# Death Muffler Fix（1.20.1 — Forge）

修复 [实用设备（Mob Grinding Utils）](https://www.curseforge.com/minecraft/mc-mods/mob-grinding-utils) 1.1.0 消声器（Death Muffler）Boss 血条隐藏功能的客户端修复模组。

## 问题背景

MUG 1.1.0 中的血条隐藏逻辑编译完整、可以运行——但它使用**硬编码的英文字符串**匹配 Boss 名称：

```java
bossName.contains("Wither")   // 或 "Dragon"
```

在英文环境下一切正常；但在其他语言环境（中文、日文、俄文……）中，Boss 血条显示的是本地化名称（如"凋灵"、"末影龙"），匹配失败，**血条隐藏功能静默失效**。

## 修复方案

本模组注册了一个额外的 `CustomizeGuiOverlayEvent.BossEventProgress` 监听器，改用 Minecraft 的**语言系统**进行名称匹配：

```java
String witherName = I18n.get("entity.minecraft.wither");     // 运行时按当前语言解析
bossName.contains(witherName) → 取消血条渲染
```

监听器读取与 MUG 相同的玩家持久数据标记（`MGU_WitherMuffle` / `MGU_DragonMuffle`，由消声器升级设置），因此隐藏行为与游戏内的消声器设置完全同步——在**任何语言**下均生效。

该监听器与 MUG 原版监听器**叠加共存**；原版监听器保持原样继续运行（包括其额外逻辑），互不冲突。英文用户体验不变；非英文用户首次获得可用的血条隐藏功能。

## 依赖要求

| 组件 | 版本 |
|---|---|
| Minecraft | 1.20.1 |
| 加载器 | Forge 47.1.106+（47.x） |
| 实用设备（MUG） | 1.1.0+（必需） |
| Java | 17 |

## 安装方法

1. 安装 Forge 和实用设备（Mob Grinding Utils）
2. 将 `death_muffler_fix-1.0.0-Forge-1.20.1.jar` 放入 `mods` 文件夹
3. 启动游戏

## 说明

- 纯客户端模组，在任何服务器（原版或模组服）上均可使用。
- 无需配置——模组根据你的消声器升级状态自动生效。
- 本模组**依赖**实用设备（Mob Grinding Utils），未安装时将拒绝加载。
