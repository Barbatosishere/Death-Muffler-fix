# Death Muffler Fix (1.21.1 — NeoForge)

A client-side fix for the **Death Muffler** boss bar hiding feature in [Mob Grinding Utils](https://www.curseforge.com/minecraft/mc-mods/mob-grinding-utils) 1.1.10.

## The Problem

Mob Grinding Utils 1.1.10 has a build defect: the class `mob_grinding_utils.events.BossBarHidingEvent` was **never compiled** — the published jar only contains its `.java` source file, without the `.class` bytecode.

The main mod class references this missing class in `doClientStuff()`:

```java
NeoForge.EVENT_BUS.register(new BossBarHidingEvent());
```

As soon as the client starts up, executing `new BossBarHidingEvent()` triggers class loading and throws `NoClassDefFoundError`, **crashing client initialization**.

## The Fix

This mod applies a **Mixin** to `MobGrindingUtils` that cancels `doClientStuff()` right before the `new BossBarHidingEvent()` instruction. Everything executed before that point (3 sound/render event registrations) is unaffected; the skipped tail logic is fully compensated:

- ✅ Boss bar hiding (Wither / Ender Dragon) reimplemented with a language-aware `CustomizeGuiOverlayEvent.BossEventProgress` listener — reads the same `MGU_WitherMuffle` / `MGU_DragonMuffle` flags, matches names via `I18n` so it works in **every language**
- ✅ XP fluid translucent render layers re-registered
- ✅ Block color handlers re-registered
- ✅ `worldUnload` cache invalidation compensated: clears MUG's cached `SPIKE_DAMAGE` on world unload (via reflection) so spike damage rebuilds with the new world's registry access

> A same-package shim class approach was tried first, but NeoForge 1.21.1's JPMS module layer rejects split packages between mod jars (`ResolutionException`), so the Mixin approach is used.

## Requirements

| Component | Version |
|---|---|
| Minecraft | 1.21.1 |
| Loader | NeoForge 21.1.230+ |
| Mob Grinding Utils | 1.1.10+ (required) |
| Java | 21 |

## Installation

1. Install NeoForge and Mob Grinding Utils
2. Drop `death_muffler_fix-1.0.0-NeoForge-1.21.1.jar` into your `mods` folder
3. Launch the game

## Notes

- Client-side only; works on any server (vanilla or modded).
- The Mixin injection point is the `new BossBarHidingEvent()` instruction; if a future MUG release fixes `doClientStuff()` and the injection point disappears, this mod fails fast at startup with a clear message instead of an obscure crash.
- This mod **requires** Mob Grinding Utils and will refuse to load without it.
